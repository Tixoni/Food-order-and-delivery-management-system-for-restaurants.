# Проверка прототипа 21.11.2026

Замеры выполнены локально в Docker Desktop. Docker выделено 12 логических процессоров и 7,6 ГиБ памяти. Использованы 50 тестовых ресторанов, две реплики шлюза и две реплики каталога. k6 обращался через nginx. Контроллеры отвечали на тестовые запросы с обычной аутентификацией Keycloak.

| Проверка                   | Порог                                                                       | Результат                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| PERF-1, каталог            | p95 ≤ 300 мс                                                                | 45,72 мс, 17 999 запросов                                                                                    |
| PERF-2, оформление         | p95 ≤ 800 мс                                                                | 217,87 мс, 73 заказа                                                                                         |
| SCAL-1, короткий пик 5:1   | 250 запросов каталога/с и 60 оформлений/мин при сохранении порогов задержки | Разгон 20 с и плато 60 с. 0 пропущенных итераций, 0 ошибок из 18 151 HTTP-запроса, 18 145 проверок прошли    |
| SCAL-3, кэш каталога       | ≥ 80% попаданий                                                             | 98,66%, 17 762 попадания и 241 промах по разнице показаний Prometheus                                        |
| PERF-3 / SCAL-4, WebSocket | ≤ 2 с и 200 одновременных соединений на экземпляре                          | 200 соединений на одном шлюзе, 100 из 100 координат получили все подписчики, p95 152,1 мс, максимум 294,8 мс |
| ADM-3 / ORD-6              | Поиск, история, отмена с причиной, частичный возврат                        | Заказ №84 найден оператором и администратором, после отмены фактически возвращено 100 копеек                 |
| OBS-3/4, метрики           | RED и показатели заказов на дашборде                                        | Prometheus опросил 7 из 7 экземпляров приложений                                                             |

Перед замером WebSocket соединения открывались группами по пять. Задержка считалась от отправки координаты до её получения последним из 200 подписчиков.

Короткий прогон использовал `LOAD_PROFILE=sample`. Для проверки устойчивости под длительной нагрузкой в сценарии есть `LOAD_PROFILE=peak` с плато 20 минут.
